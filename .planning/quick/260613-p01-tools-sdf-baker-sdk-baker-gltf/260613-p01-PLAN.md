# Quick Task: tools/sdf_baker support glTF

## Goal

Extend the offline `sdf_baker` mesh input path so it can bake triangle meshes from `.gltf` and `.glb` files while preserving existing `.obj` behavior.

## Tasks

1. Update the baker API and CLI to load meshes by extension and advertise OBJ/glTF/GLB support.
2. Add a tinygltf-based mesh reader that extracts triangle primitives, applies node transforms, handles indexed and non-indexed primitives, and rejects unsupported topology/accessor formats with clear errors.
3. Link the `sdf_baker` target against the existing `tinygltf` dependency and verify the target builds.

## Verification

- Configure/build `sdf_baker`.
- Run targeted source scans for the new glTF entry points.
