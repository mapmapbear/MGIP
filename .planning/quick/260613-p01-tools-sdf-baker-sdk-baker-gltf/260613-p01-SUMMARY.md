# Summary

Extended `tools/sdf_baker` so the CLI accepts `.obj`, `.gltf`, and `.glb` inputs.

## Changes

- Added `loadMesh` extension dispatch and a `loadGltf` geometry path using tinygltf.
- Extracted glTF triangle primitives from the active scene, applying node matrix/TRS transforms.
- Supported indexed and non-indexed glTF triangle primitives with bounds checks and clear errors for unsupported topology, sparse accessors, and invalid accessors.
- Linked the standalone `sdf_baker` target against the existing `tinygltf` dependency.
