# Quick Task: DDGI Mesh SDF UI Loading

## Goal

Add UI controls that load a mesh SDF asset derived from the active glTF path and wire it into the DDGI runtime.

## Tasks

1. Add renderer facade/runtime entry points to load a mesh SDF file, enable DDGI, initialize DDGI resources on demand, and attach the loaded SDF texture to `GlobalSDFPass`.
2. Add Model Loader UI controls for the derived SDF path, with `sponza.gltf -> sponza_sdf.gltf` as the preferred naming and `_SDF.bin` fallback.
3. Verify with a desktop build of the modified target.
